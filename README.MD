# Mining Fatigue 3 Fix 挖掘疲劳3修复

在26.2及以前版本中，原版游戏的挖掘疲劳3的挖掘速度乘数被错误地设置为0.27%，导致玩家的挖掘速度及其缓慢。在26.3，挖掘速度乘数被修复为2.7%. 该模组旨在修复26.2及以前版本中的挖掘速度乘数。

In versions 26.2 and earlier, the mining speed multiplier for Mining Fatigue 3 in the original game was incorrectly set to 0.27%, resulting in extremely slow mining speeds for players. In version 26.3, the mining speed multiplier was corrected to 2.7%. This mod aims to fix the mining speed multiplier for versions 26.2 and earlier.
